# Design direction

Direction for henrinnes.github.io, from Henry's answers (22 October 2026). Not published on the site.

- **Audience:** employers and recruiters in security. Lead with what Henry has built and shown.
- **Feel:** calm and academic. Quiet, readable, content first, few effects.
- **Signature:** the Agentic SABRE triage colours (contain, escalate, allow) are the site's visual motif.

Dial: ENERGY 1 / RHYTHM 2 / MOTION 1

## Decisions and reasons

- **Type:** Source Serif 4 for headings, for a journal-like academic voice. Source Sans 3 for body text, a companion family built for long-form reading. Code uses the system monospace.
- **Colour:** a warm off-white "paper" ground with near-black text. Teal is the only interactive colour (links and buttons). The contain (red), escalate (amber) and allow (green) colours appear only where they carry meaning: the triage diagram and the triage-scale motif.
- **Motif:** a short three-segment rule in the triage colours under page and section headings. It echoes the contain / escalate / allow policy at the centre of the research.
- **Layout:** each section has its own shape: split hero with the triage diagram, a lead project with two smaller ones, a dated post list, and a contained signup panel. Agentic SABRE gets the most room because it is the flagship work.
- **Surfaces:** flat, with borders and no drop shadows. Shadow is kept only for things that overlay the page (the mobile menu and the skip link).
- **Shape:** 10px radius on panels, 6px on buttons and fields, 4px on tags. No pill shapes.
- **Motion:** hover colour changes only. No lifts, fades or loops.
- **Dark mode:** a working toggle that follows the system setting by default.
