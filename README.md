# Henrinnes.github.io

Personal blog of Henry Kabuye, published at <https://henrinnes.github.io>.

Write new posts as Markdown files in `_posts/`, named `YYYY-MM-DD-title.md`.

To preview locally:

```
gem install jekyll jekyll-paginate
jekyll serve
```

Built with the [Lanyon](https://github.com/poole/lanyon) Jekyll theme by Mark Otto, released under the [MIT license](LICENSE.md).
