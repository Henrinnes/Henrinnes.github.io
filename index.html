Selected work

Expert Systems with Applications, 2026

Agentic SABRE

An uncertainty-aware, multi-agent ransomware detector. Instead of one classifier making every call, three specialised agents each report a risk score and how confident they are, and a triage policy decides whether to contain, escalate or allow.

Paper Write-up Code

What I built

  • Semantic, behavioural and knowledge agents, each a 1D CNN with Monte Carlo dropout for uncertainty
  • A decision agent and risk- and uncertainty-aware triage policy
  • A Streamlit dashboard for inference, calibration, explainability and live attack-stream simulation

Dataset, 2026

RansKnow

1,128 security talks and briefings from 92 channels, turned into 37 MITRE ATT&CK-aligned features per video: ransomware families, tactics, tools and platforms. It feeds the knowledge agent in Agentic SABRE.

EU COVER project, 2026

Private data sharing for UAV fleets

A federated learning framework for drones with blockchain security, incentives and differential privacy. I found and fixed two privacy-accounting bugs, which turned an apparently unlearnable private model into one that learns under ε ≤ 10.
